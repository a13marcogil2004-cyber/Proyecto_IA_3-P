# Calculadora con Historial

Proyecto desarrollado como parte del tutorial de Python básico-intermedio,
implementado para la materia de Programación y Tecnologías Emergentes en CETI,
6° Semestre Mecatrónica.

## ¿Qué hace?

Es una calculadora que corre en la terminal. Permite hacer operaciones básicas
y guarda cada resultado en un archivo de texto para consultarlo después.
También puedes borrar ese historial cuando quieras.

Operaciones disponibles:
- Suma, resta, multiplicación y división
- Potencia
- Ver historial de operaciones anteriores
- Borrar historial

## Requisitos

- Python 3.8 o superior
- No necesita instalar ninguna librería externa

## Conceptos aplicados

- Funciones con parámetros y retorno
- Manejo de errores con try/except
- Diccionarios para mapear opciones
- Lectura y escritura de archivos con open()
- Módulo os para manejo del sistema de archivos
- Ciclos while y menús interactivos
